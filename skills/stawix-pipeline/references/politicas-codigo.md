# Políticas de código

> **Pendente:** este arquivo será preenchido com as políticas dos manuais do Vinicius. Até lá, siga apenas as regras abaixo e, em caso de dúvida de estilo, siga o padrão já usado no projeto.

## Regras provisórias

- Siga o estilo e a estrutura que o projeto já usa; não reorganize o que não faz parte da tarefa.
- Toda mudança de comportamento vem acompanhada de teste.
- Rode o lint e os testes do projeto antes de entregar.
- Não deixe código comentado, `print` de depuração ou TODO sem card.
- Nada de segredo, senha ou token no código ou no repositório.
